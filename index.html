Connecting to GenLayer...
How it works. A buyer locks real native GEN against human-readable terms. Both parties submit authenticated, append-only evidence. On resolve, an LLM judges the evidence and validators reach consensus via the Equivalence Principle; the consensed verdict controls a replay-safe payout that actually transfers the held GEN to the seller (RELEASE) or back to the buyer (REFUND). This page reads that state live; no wallet needed.
Examples: 0x829DB851bc9963c71B22305e3b73bf5B220D1462 is a contested case resolved REFUND with evidence from both parties. Paste 0x679f4657d126Aa973A070E59654b6B8c37EaA7c0 for a fully-settled RELEASE (funds delivered to the seller, contract balance 0).
